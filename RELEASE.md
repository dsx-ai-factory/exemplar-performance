# Releases and Support

## Versions and Release Notes

Exemplar uses calendar-style release tags, such as `v26.10.02`. The year and month identify a release line, with a final component for updates within that line. Some older tags omit the final component. CLI packages have their own versions.

[Public releases](https://github.com/dsx-ai-factory/exemplar-performance/releases) and [CHANGELOG](CHANGELOG) record release dates, changes, known issues, and support announcements. Use a published tag and record its commit for reproducible work. Maintainers tag the reviewed commit and publish its release notes on GitHub Releases.

## Support and Security

Consult the **End of Support** entries in `CHANGELOG`. As announced in `v26.10.00`, `v26.06.x` and earlier receive no further updates, fixes, or support. Check the README and recipe documentation at the chosen tag for supported hardware, schedulers, and software versions.

Report security issues privately using [SECURITY.md](SECURITY.md). Vulnerability response and remediation follow [NVIDIA PSIRT policies](https://www.nvidia.com/en-us/security/psirt-policies/).
