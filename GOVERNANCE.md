# Governance

Maintainers guide Exemplar Performance through reviewed changes and documented decisions. [MAINTAINERS.md](MAINTAINERS.md) records responsibility for each area.

## Decisions

The NVIDIA maintainer team reviews proposed changes and makes project decisions. Contributors can propose changes through issues or pull requests.

## Maintainer Changes

The NVIDIA project team appoints its own members as maintainers, handles removals, and manages repository access. For inactive maintainers, the team arranges a handoff and updates repository access.
