# Maintainers

Exemplar Performance is maintained by the Exemplar Performance maintainers at NVIDIA.

## Ownership

The maintainer group shares responsibility for the Exemplar tools, recipes, integrations, and documentation listed below. Upstream frameworks such as NeMo are maintained by their own project teams.

| Area             | Scope                                                                |
| ---------------- | -------------------------------------------------------------------- |
| CLI tools        | Installation, job submission, and result collection in `cli/`        |
| Workload recipes | Training, fine-tuning, reinforcement learning, and inference recipes |
| Shared tools     | `common/`, `microbenchmarks/`, and repository automation             |
| Documentation    | Project guidance, validation instructions, and recipe documentation  |

Maintainers review contributions, triage issues, and coordinate releases. Maintainer membership and repository access are managed through repository permissions.

## Contact

Request review or discuss project work in a GitHub issue or pull request. For questions or feedback, contact [LLMBenchmarks@nvidia.com](mailto:LLMBenchmarks@nvidia.com). Use [SECURITY.md](SECURITY.md) for vulnerability reports and the [Code of Conduct](CODE_OF_CONDUCT.md) for conduct reports.

See [GOVERNANCE.md](GOVERNANCE.md) for decisions, maintainer changes, and inactive maintainers.
